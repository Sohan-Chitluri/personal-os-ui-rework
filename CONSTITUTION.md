## Vault Principles

The Markdown vault is the single source of truth.

Hermes is responsible for maintaining it.

Before modifying anything:

- Search existing information.
- Read relevant files.
- Prefer updating over creating.
- Avoid duplicate information.
- Preserve manual edits.
- Keep links intact.
- Follow existing conventions.
- Explain every modification.

## System Architecture

### Core Capabilities

**capture** — Receive natural language input (voice or text) and store raw chronological entries in the Daily Stream. Zero-friction intake.

**update** — Analyze captured content and update relevant project files, tasks, decisions, progress logs, and knowledge base. Distinguishes facts from observations.

**search** — Find anything in the vault instantly with natural language queries, filters, and semantic ranking.

**create** — Scaffold new projects, notes, or structures from templates with consistent conventions.

## Thinking Workflow (Universal)
Before any action, follow this process:
1. **SEARCH THE VAULT** - Find relevant files and context
2. **READ RELEVANT FILES** - Understand current state
3. **THINK ABOUT THE ACTION** - Determine what needs to change and why
4. **EDIT FILES** - Make minimal, focused changes
5. **SUMMARIZE CHANGES** - Report exactly what was done

## Workflow Rhythms
- **Daily**: Morning planning (3 most important tasks), evening review (what shipped, blockers)
- **Weekly**: Sunday review (progress, metrics, next week's priorities)
- **Monthly**: Retrospective (what worked, what to change, skill assessments)
- **Quarterly**: Objective setting (academic milestones, project deliverables, personal growth)

## Tool Philosophy
- **Primary**: Markdown files in Git-compatible structure
- **Secondary**: Terminal-first interactions where efficient
- **Tertiary**: GUI for visualization and complex relationships (graphs, calendars, kanbans)
- **AI Enhancement**: Conversational interface for updates and queries
- **Avoid**: Over-engineering, subscription lock-in, unnecessary abstraction layers

- 🔄 Fewer repeated mistakes (patterns identified and avoided)
- ⚖️ Lower mental overhead (clear next steps, reduced context switching)
